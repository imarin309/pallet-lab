# Palette Lab — ゲームコンセプト

> ドキュメント種別：ゲームコンセプト（Why / What）  
> ステータス：v0.1・検証前  
> 関連文書：[ゲーム仕様書](./palette-lab-game-spec.md)

## 1. ゲームの一言紹介

**限られた塗料を混ぜて理想の色に近づける、引き際が重要な調色パズルゲーム。**

プラモデルの筆塗り塗装で行う「調色」を、誰でも短時間で楽しめるブラウザゲームにする。

## 2. コアコンセプト

> あと1滴で理想の色になるかもしれない。でも、今の色を壊してしまうかもしれない。

このゲームの主役は「色を作ること」そのものだけではなく、**「次の1滴を足すか、ここで完成とするか」という判断**。

プレイヤーは目標色と現在の色を見比べ、次の一手を予想する。試行錯誤を通じて、色を見る感覚と判断に自信がついていく体験を目指す。

## 3. プレイヤーに届けたい体験

1. **予想する楽しさ**：次に何色を混ぜれば近づくのか考える。
2. **変化する気持ちよさ**：1滴落とすたび、パレットの色が変わる様子を楽しむ。
3. **攻めるか守るかの葛藤**：十分近い色を作れたとき、もう1滴足すか迷う。
4. **納得できる失敗**：色が遠ざかった理由を振り返り、次の判断に活かせる。
5. **上達の実感**：繰り返すほど混色の傾向をつかみ、前より近い色を作れる。

目指すプレイ感は、**気軽に始められて、思わず「もう1回」と言いたくなる**こと。焦らせるアクションではなく、観察と判断を楽しむ。

## 4. ゲームの中核となる意思決定

ゲームの中心となる問いは、次の2つ。

- **次に何色を足す？**：目標に近づく可能性と、逆に遠ざかる可能性を比較する。
- **まだ続ける？**：現在の成果を確定するか、より高い得点を狙って調色を続けるか選ぶ。

### リスクとリターンの考え方

| 判断 | 得られる可能性 | 失う可能性 |
| --- | --- | --- |
| 色をさらに足す | 目標色に近づく | 色を悪化させる・残りの手数を消費する |
| やり直しの機会を使う | 失敗を修正する | 次の失敗への備えがなくなる |
| 早めに完成する | 今の成果を確定する | さらに改善できた可能性を逃す |

**重要なのは、失敗をランダムな罰にしないこと。** 行動と結果の因果関係が分かれば、「自分の判断で挑戦した」と感じてもらえる。

滴数や取り消し回数など、具体的な数値と処理はゲーム仕様書で定める。

## 5. 報酬設計の方針

報酬は3段階で考える。

### 瞬間的な報酬：操作自体が楽しい

滴がパレットに落ち、色がじわっと変化する。良い判断をする前の段階でも、操作したくなる手触りを作る。

### 短期的な報酬：挑戦が評価される

目標色との近さを点数やランクで可視化する。結果には改善のヒントも添え、得点が低い場合も次の挑戦につながるようにする。

### 長期的な報酬：上達と成果が残る

自己ベストを更新する喜びを中心にする。将来的には作った色を集めて眺める「マイカラーチャート」や、集めた色でロボットのパーツを塗る体験へつなげる。

※ コレクション機能は初期版の実装対象には含めない。

## 6. ゲームとして大切にする原則

1. **学べる一貫性**：同じ材料を同じ割合で混ぜた結果は変わらない。
2. **直感と納得感**：絵の具を混ぜる感覚から大きく外れないことを目指す。
3. **駆け引きを生む制約**：限られた手数と救済手段が、判断の意味を作る。
4. **結果が次につながる**：失敗しても改善する方向が分かる。
5. **気軽に遊べる**：説明や準備に時間をかけず、短い時間で一区切りつく。
6. **表現より遊びを優先**：派手な演出より、色を観察し判断する面白さを先に検証する。

## 7. 想定ユーザー・利用シーン

- 色を作ることやパズルが好きな人
- プラモデル・イラスト・絵の具に親しみがある人
- ちょっとした空き時間にブラウザで遊びたい人

プラモデルの知識は前提としない。1ステージは短く、PCでもスマートフォンでも気軽に楽しめることを目指す。

## 8. 面白さに関する仮説

| 仮説 | プレイテストで確かめたいこと |
| --- | --- |
| A. 引き際に葛藤が生まれる | 「もう1滴足すか」で実際に迷うか |
| B. 混色は学習可能である | 次に足す色を予想でき、繰り返すほど上達するか |
| C. 小さな演出が気持ちいい | 色の変化や滴の演出が操作したくなる理由になるか |
| D. 評価が再挑戦を促す | 点数とヒントを見て、もう一度遊びたいと思うか |

試作後は、数人に最小限の説明で遊んでもらう。「面白かった？」だけでなく、**どの場面で迷い、何が起きると予想したか**を聞く。

## 9. このプロジェクトの開発背景

普段行っているプラモデルの筆塗り塗装を題材に、ゲーム開発という新しい領域に挑戦する個人制作プロジェクト。

技術的な構成や画面遷移、詳細なルールは別紙の[ゲーム仕様書](./palette-lab-game-spec.md)で管理する。
